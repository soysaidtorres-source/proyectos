MAPA DE DISPARADORES
==================================================

Primer mensaje del contacto        -> plantilla_bienvenida
"qué incluye" / "precio" / "info"  -> plantilla_precios (o lo responde el bot)
"lo quiero" / "quiero inscribirme" -> el BOT manda el paso a paso + link (o plantilla_checkout si así lo decides)
+2 minutos después del link        -> plantilla_video_inscripcion (con el video adjunto)
Envía captura / "ya pagué"         -> plantilla_confirmacion_comprobante
Pago verificado (tú)               -> etiqueta CLIENTE + plantilla_entregable
Sin compra +2 horas                -> plantilla_remarketing_1
Sin compra +20-22 horas            -> plantilla_remarketing_2
Sin compra +48 horas               -> plantilla_remarketing_3
Sin compra +4-5 días               -> plantilla_remarketing_4 (último)
Respuesta "1" al remarketing_4     -> el BOT manda el paso a paso + link
Respuesta "3" al remarketing_4     -> etiqueta NO_INTERESADO (sin más mensajes)
Duda de confianza / pide pruebas   -> plantilla_testimonios

ETIQUETAS RECOMENDADAS: CHECKOUT_ENVIADO · CLIENTE · NO_INTERESADO
Los remarketing se envían solo si el contacto NO tiene la etiqueta CLIENTE.
La etiqueta CLIENTE es tu registro de ventas para saber qué anuncios venden.
